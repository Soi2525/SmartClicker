# Smart Clicker · by Soi

**RU** · [EN ↓](#english)

Автоматизация для игры в эмуляторе **BlueStacks 5** или **MuMu Player** на Windows.
Мышь остаётся свободной: клики идут в эмулятор напрямую, можно заниматься своими делами.

## Что умеет

**Питомец — прокачка статов**
- Видит все 6 статов и их изменения после каждой попытки.
- Сам жмёт «Повторить» и «Заменить», когда результат подходит.
- Качает статы в выбранном вами порядке и останавливается, когда всё на максимуме.
- Когда кончаются камни, закрывает окно покупки и останавливается. Ничего не покупает.

**Охота на ужасов — рейды**
- Сам находит ужасов нужных уровней (1–7, по кругу) и запускает рейды на 3 или 5 минут.
- Использует только то число маршей, которое вы разрешили. Ваши остальные марши не трогает.
- Новый рейд запускает, когда возвращается один из своих.
- Если на ужаса уже собирается другой игрок, ищет другого.
- Работает, пока есть выносливость.
- Встаёт на паузу, если открыть чат или другое окно игры.

**Удобно**
- **F7** — пауза / продолжить, **F8** — стоп.
- 5 языков: English, Русский, Українська, 中文, العربية.
- Сам находит открытый эмулятор.

## Установка

1. Скачайте **SmartClicker_Setup_7.1.exe** в разделе [Releases](../../releases/latest) и запустите.
2. Если Windows пишет «Система Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае**.
   Это обычное предупреждение для программ небольших авторов без платного сертификата.
3. При первом запуске появится экран активации. Нажмите «Скопировать» рядом с **ID компьютера** и отправьте его автору в [Discord](https://discord.gg/sAmdXGythn). Полученный код вставьте кнопкой «Вставить» или Ctrl+V.

## Настройка эмулятора (один раз)

Экран эмулятора: **1080 × 1920, вертикальный («телефон»)**.

- **BlueStacks 5:** Настройки → Дополнительно → включить «Android Debug Bridge (ADB)» → Сохранить → перезапустить BlueStacks.
- **MuMu Player:** Настройки → Другое → Отладка ADB → включить локальное подключение; Экран → Телефон 1080 × 1920.

## Требования

Windows 10 / 11 (64-бит) и BlueStacks 5 или MuMu Player.

## English

Automation for the game in **BlueStacks 5** or **MuMu Player** on Windows.
Your mouse stays free: clicks go straight into the emulator.

**Pet stats:** reads all 6 stats after every attempt and presses "Retry" / "Replace" when the result fits. It upgrades stats in your chosen order and stops when they are maxed. When stones run out, it closes the purchase window and stops; it never buys anything.

**Horror hunt:** finds horrors of the chosen levels (1–7, round-robin) and starts 3 or 5 minute rallies.
- Uses only the number of marches you allow and leaves your other marches alone.
- Starts a new rally when one of its own returns, and skips horrors someone else is already rallying.
- Runs while stamina lasts and pauses when the game chat or another window is open.

**F7** pause / resume, **F8** stop · 5 languages · finds the open emulator automatically.

### Install

1. Download **SmartClicker_Setup_7.1.exe** from [Releases](../../releases/latest) and run it.
2. If Windows shows "Windows protected your PC", click **More info → Run anyway**.
3. On first start, click "Copy" next to your **computer ID**, send it to the author on [Discord](https://discord.gg/sAmdXGythn), then paste the code you receive ("Paste" button or Ctrl+V).

### Emulator setup (once)

Screen **1080 × 1920 portrait ("phone")**.
- **BlueStacks 5:** Settings → Advanced → enable "Android Debug Bridge (ADB)" → Save → restart.
- **MuMu Player:** Settings → Other → ADB debugging → enable local connection; Display → Phone 1080 × 1920.

Windows 10 / 11 (64-bit).
